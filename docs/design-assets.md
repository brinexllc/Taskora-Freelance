# Ресурсы интерфейса — актуальный реестр

Дата сверки файлов: 13.09.2026. Этот реестр заменяет прежнее утверждение README об отсутствии After. Бинарные файлы шрифтов и секреты в отчёт не включены.

| Ресурс | Место в проекте | Назначение | Статус прав |
| --- | --- | --- | --- |
| After | `frontend/public/fonts/After ttnorm.ttf` | Заголовки с поддерживаемыми глифами | Есть сопроводительный `After ttnorm-COPYRIGHT.txt`; подтверждение лицензии на коммерческое web-встраивание должен предоставить владелец |
| Helvetica Neue Thin/Light/Roman/Medium/Bold | `frontend/public/fonts/HelveticaNeue-*.otf` | Основной текст и кириллический fallback | Есть `Helvetica Neue-COPYRIGHT.txt`; copyright notice не заменяет подтверждение приобретённой лицензии |
| PNG логотипы | `frontend/public/brand/` | Цветной/белый логотип и знак из ранее предоставленных ресурсов | Происхождение описано в design-rebuild; разрешение владельца на бренд не заменяет сторонние лицензии |
| Lucide icons | Зависимость `lucide-react` в package/lockfile | Иконки компонентов | Использовать с лицензией установленного пакета |

Текущая карта экранов — `docs/design-rebuild.md`; текущая проверка интерфейса и её ограничения — `docs/frontend-audit.md`. Макеты Figma и старые экспортированные снимки не являются результатом новой приёмки. Подтверждать 1:1 можно только после доступа к указанной исходной ветке и проверки соответствующих кадров.
